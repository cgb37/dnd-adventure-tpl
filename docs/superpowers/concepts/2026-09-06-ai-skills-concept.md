# AI Skills for Gameplay Concept

For brainstorming agent: break this plan up into phases. Do not overwhelm with an end-to-end build.

**Goal**

Agentic AI Skills
- dm-guide
- players-handbook
- encounter-generator
- location-generator
- monster-generator
- magic-generator
- dm-orchestrator

The dm-orchestrator is the most complex. It can call any other skill to achieve its objective.

It should have a memory for the campaign.
It should be able to generate a campaign outline that it leads the player through.
Use story hooks, puzzles, unreliable narrators, individual agendas, all the things that make for a good story.

The dm-guide and players-handbook skills should be abbreviated rules, guidelines, for the respective audience.

everything should be created with a cohesive story in mind, so the locations, encounters, etc should be story appropriate.

also, they should be level appropriate and employ CR ratings and best judgement.
